# Abhinoor Singh — Portfolio

Personal portfolio website for Abhinoor Singh, showcasing my work, skills, projects, experience, and interests.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- React Router
- Three.js
- React Three Fiber
- Radix UI
- Express
- Vitest

## Features

- Responsive portfolio layout
- Interactive UI and animations
- Project showcase
- Skills and experience sections
- Modern component-based architecture
- Responsive design for desktop and mobile
- Interactive visual elements powered by Three.js
